# Easy-Switch channel events · 0.5.1

Select the Keyboard tab and the exact keyboard. “Watch Easy-Switch” saves an explicit opt-in through OpenLogi’s public API and starts one agent-only stream. Stop ends that child process immediately and asks OpenLogi to disable the flag. If disabling is not acknowledged, the card says so; no retry or other device is chosen.

The API requires the matching OpenLogi app/agent/CLI update. Older protocol-32 installations retain mouse controls and connection/battery events; host-button watching stays unavailable. API detection is read-only and writes never fall back to a second command format.

To connect an Ark, allow Odyssey Ark to receive this module’s “Keyboard Easy-Switch choices” and “Selected keyboard Easy-Switch watch” channels in NeroNook Settings → Modules. In Ark’s primary card, select a source for each channel, test it physically, mark it verified, choose the permitted keyboard provider and select Follow keyboard. Stop following stays in the same card. Default mapping: 1 → HDMI 1, 2 → DisplayPort, 3 → HDMI 2.

No direct HID, ordinary typing, OpenLogi profile edits or monitor transport belongs to this module. OpenLogi owns analytics reporting and restoration. Firmware without reportable host keys is unsupported. The stream’s initial baseline proves an IPC connection, not a captured physical press. A fresh physical press and actual monitor source response are separate acceptance steps.

This Mac sees choices while the keyboard is connected here, plus a measured return after this agent observed departure. It cannot hear switching between two other computers. Restarting the Ark plugin or losing its provider requires explicitly enabling following again; old choices are never replayed.

Verification: 25 Swift tests; signed isolated connection/battery regression and host-choice stream fixtures; live read-only legacy handshake. Physical keyboard/monitor acceptance is tracked in reports/easy-switch-2026-10-14/README.md.

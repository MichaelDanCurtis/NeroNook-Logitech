# Logitech module
Build, install and release independently of NeroNook. Use only the vendored NookPluginSDK for host integration. The installed OpenLogi application/agent owns HID and permissions; never open devices, edit its profile files or bundle its brand assets. Use the compatible agent-backed CLI without shell evaluation, arbitrary command arguments or write retries. Read-only polling must never write or silently retarget another device. A failed refresh disables controls. Device-changing SDK actions require the host's normal review and explicit targets. Keep external app dependency and protocol requirements visible. Test parsing, unavailable states, targeting and writes with injected runners; distinguish those tests from live hardware verification. Native presentation keeps the SDK's 16:9 stage and a single status line.
